# CS50-Python
CS50’s Python, offered by Harvard University, is an introductory course that teaches the fundamentals of programming using Python. It covers key topics such as:

Variables, data types, and functions

Loops and conditionals

File handling and exception handling

Object-oriented programming

Regular expressions and testing

Web programming with Flask

The course includes hands-on exercises and problem sets to reinforce learning, making it ideal for beginners in programming. No prior coding experience is required.

For more details, visit: cs50.harvard.edu/python
